# 🛡️ Mini Wireshark — Network Packet Analyzer

A professional network packet analyzer built with **Python, Scapy, and Streamlit** for capturing, filtering, and analyzing network traffic on a local system.

## 🚀 Project Overview

Mini Wireshark is a lightweight packet analysis tool inspired by Wireshark. It provides a user-friendly dashboard for monitoring network packets and inspecting basic network traffic information in real time.

The project focuses on learning **network protocols, packet analysis, Python networking, and cybersecurity concepts**.

## ✨ Features

* 📡 Capture network packets using Scapy
* 🔍 Inspect IP, TCP, and UDP packet information
* 🎯 Filter packets by protocol
* 📊 Display network traffic statistics
* 📈 Visualize protocol distribution
* 🌐 Identify source and destination IP addresses
* ⚠️ Detect visible unencrypted HTTP traffic
* 🖥️ Interactive Streamlit dashboard
* 📦 Display packet size and port information
